# ✈️🐱 Kapten Kitty & Pesawat Cinta 360° (Romantic Pixel Web)

Web romantis interaktif bertema **Retro Pixel 8-Bit** dengan nuansa cerah ceria (**Bright Pastel Cotton-Candy Sky**), tombol balok timbul **3D non-transparan**, musik chiptune lucu & gemas, kuis cinta, surat rahasia, serta mini-game **Space Shooter Multi-Level** untuk menaklukkan **Semesta Hati**!

Dibuat spesial untuk mengungkapkan rasa kangen mendalam dengan cara yang manis, interaktif, dan tak terlupakan! 💖

---

## 🌟 Fitur Utama

1. **🛸 Pesawat 3D 360° Bebas (Three.js & Canvas Depth-Sorted Engine):**
   * Dikemudikan oleh **Pilot Meow** (Kucing Chibi) berkacamata penerbang & pipi merona.
   * Bisa diputar bebas **360 derajat** ke segala arah (drag mouse / layar sentuh HP).
   * Dilengkapi **Slider 360°** presisi, indikator sudut real-time (`0° - 360°`), tombol salto (*Barrel Roll* 🌀), dan tombol *Auto-Rotate*.
   * Tersedia pula **Mode 2D Radar Orbit** mengelilingi pulau cinta.

2. **🎵 3D Pixel Jukebox (4 Pilihan Musik 8-Bit Imut & Gemas):**
   * 🐾 **1. Bouncing Kitty Love** (Melodi melompat-lompat ceria ala Animal Crossing & Kirby)
   * ✈️ **2. Chibi Airplane Flight** (Irama petualangan retro penuh semangat)
   * 🧋 **3. Strawberry Boba Pop** (Nada manis teman jajan boba)
   * 💖 **4. Peluk Pilot Meow** (Melodi lembut bikin melting)
   * Menggunakan *Web Audio API* prosedural (ringan, instan, tanpa file MP3 eksternal).

3. **✨ Partikel Ledakan Tiap Klik Tombol:**
   * Setiap tombol di web akan memancarkan letupan partikel bintang, hati, kilauan, dan cakar kucing (`✨`, `💖`, `⭐`, `🐱`, `🐾`) saat ditekan!

4. **📝 Kuis Romantis: "Seberapa Kangen Kamu?":**
   * 3 pertanyaan interaktif untuk mengukur level rasa kangen si pembuka web.
   * Skor diagnosis otomatis (*"Kangen Tingkat Dewa 1000%!"*).

5. **✉️ Amplop Surat Rahasia 3D:**
   * Amplop interaktif yang bisa diklik untuk membuka surat cinta tulus dari hati si pembuat web.

6. **🎯 Misi Tangkap Hati & Pilihan Tebusan Kangen:**
   * Misi menangkap 5 Love Pixel di layar.
   * Pilihan tebusan kangen (Traktir Boba/Es Krim 🧋, Peluk Erat 10 Detik 🤗, VC Malam Ini 📞, Kirim PAP Senyum Manis 📸, Date Weekend Ini 🎡).

7. **🚀 Mini-Game Space Shooter ("Semesta Hati Aku"):**
   * Membuka pintu rahasia menuju arcade game tembak-tembakan menggunakan **pesawat kucing utama**:
     * ☁️ **Level 1:** Langit Awan Ragu (Kalahkan 5 musuh awan).
     * 👾 **Level 2:** Orbit Overthinking (Kalahkan 6 alien overthinking).
     * 👑 **Level 3:** **BOSS BATTLE: Raksasa Rindu & Gengsi** lengkap dengan Bar Darah Boss (Boss HP)!
     * ❤️ **Sistem Tabrakan & Nyawa:** Pesawat memiliki 3 nyawa. Jika tertabrak musuh atau peluru boss, nyawa berkurang dan bisa Game Over!
     * 🏆 **Kemenangan:** Mengalahkan boss terakhir untuk secara resmi mendapatkan *"Semesta Hati Aku"* seutuhnya!

8. **💌 Tombol WhatsApp Solid 3D (Non-Transparan):**
   * Menghubungkan langsung ke target WhatsApp: **`+62 896-7403-7725`**.
   * Format pesan otomatis merangkum: **Hasil Kuis + Status Kemenangan Boss Game + Lagu Favorit + Tebusan Kangen**.

## 🚀 Cara Menjalankan & Upload ke GitHub

### 1. Menjalankan di Komputer / HP Sendiri:
Tinggal klik 2x file `index.html` dan buka di browser apa saja (Google Chrome, Edge, Safari, dll.).

### 2. Cara Upload ke GitHub & Bikin Link Online (GitHub Pages):
1. Buat repository baru di [GitHub](https://github.com/new), misalnya beri nama: `romantic-pixel-flight`.
2. Upload semua file ini (`index.html`, `style.css`, `app.js`, `README.md`) ke repository tersebut.
3. Buka tab **Settings** di repository GitHub kamu.
4. Di menu sebelah kiri, klik **Pages**.
5. Di bagian *Branch*, pilih `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
6. Dalam 1 menit, GitHub akan memberikan link website gratis (contoh: `https://username.github.io/romantic-pixel-flight/`).
7. Kirimkan link tersebut ke dia! 💖
